## 2. 技术实现方案

### 2.1 文件创建
- 创建 `src/views/Login.vue`

### 2.2 核心组件 (TDesign Mobile Vue)
- **Logo**: 使用 `<t-image>` 或 `<img>`
- **输入框**: 使用 `<t-input>`
  - 用户名: `v-model="formData.username"`
  - 密码: `v-model="formData.password"`, `type="password"`, 配置 `suffixIcon` 实现显隐切换
- **协议勾选**: 使用 `<t-checkbox>`
- **按钮**: 使用 `<t-button>`，绑定点击事件 `handleLogin`

### 2.3 数据与逻辑
- 使用 `reactive` 定义表单数据 `formData`
- 实现简单的表单校验（非空校验、协议勾选校验）
- 模拟登录请求处理

### 2.4 样式 (SCSS)
- 使用 `.page-container` 作为根容器类
- 使用 Flex 布局实现垂直居中或顶部偏移布局
- 调整各元素间距 (`margin-bottom`) 以符合视觉规范

### 2.5 路由配置
- 在 `src/router/index.ts` 中添加 `/login` 路由配置
